# AI/ML 101: From Data to MiniGPT

A 12-week, nine-module course for high school students who have programmed before. Explore the math, experiments, and social choices behind machine learning, then train a small transformer. No prior machine learning is required. Allow about 3–5 hours per week. A teacher can adapt the pace.

> The referenced conversation confirmed the audience, nine-module/12-week scope and transformer capstone; its detailed curriculum text was unavailable to the thread reader. This is a newly reconstructed course, not a verified transcription of that curriculum.

## Start here

1. Read [the syllabus](SYLLABUS.md) and [student guide](STUDENT_GUIDE.md).
2. Start with [Module 1](modules/01-ai-data-and-responsible-use/lesson.md). Each lesson links its notebook and assignment.
3. On GitHub, open a `.ipynb` file to read it. To run in Colab, open [Colab](https://colab.research.google.com/), choose **GitHub**, and paste the notebook's GitHub URL; for a downloaded copy choose **Upload**. Select Runtime → Run all. The first eight labs use only Python's standard library. The capstone requires PyTorch, normally preinstalled in Colab; a CPU is sufficient for the small default run.
4. Submit work according to your teacher's instructions. Do not commit personal or sensitive data.

For local use, install Python 3.9+, Jupyter and PyTorch for the capstone; see [setup](STUDENT_GUIDE.md). Lessons and exercises can be read without an account. Notebooks can be uploaded to Colab without a repository URL.
