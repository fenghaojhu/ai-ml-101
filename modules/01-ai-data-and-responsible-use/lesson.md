# Module 01: AI, data and responsible use

**Week(s):** 1  
**Learning goal:** Distinguish AI, machine learning and generative models; describe a prediction task and its limitations.

## Learn

A model learns a mapping from examples. A feature is information available at prediction time; a label is the outcome to predict. Training examples approximate a population, so collecting only convenient examples can leave groups out. A model can be accurate overall and still harm people in a subgroup.

## Worked example

A school wants to predict bus delays. Weather and route are possible features; whether the bus was late is a label. Student names are not needed.
