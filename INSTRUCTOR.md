# Instructor guide

Use the syllabus pacing as a starting point. The first eight labs use small synthetic examples and run with the Python standard library. Discuss data representation and uncertainty before optimization. Model a train/validation/test split and emphasize that student experiments using the test set repeatedly no longer provide a final unbiased evaluation.

Weeks 2–3: draw vectors and approximate a derivative before introducing notation. Week 4: have students identify leakage. Weeks 5–7: connect loss, gradients, activations and model evaluation. Weeks 8–10: introduce tokenization, then compute a masked attention example. Weeks 11–12: conference on each capstone proposal; check data permission and feasibility before training. The default tiny corpus is synthetic and the capstone runs on CPU; allow extra time for dependency setup and experiments.

Use the [rubrics and quizzes](assessments/README.md). The [answer guide](assessments/answer-guide.md) is included for self-study; move it to a private location if using the questions as closed-book assessment. Facilitate discussion of bias, privacy and misuse without asking students to reveal personal information.
